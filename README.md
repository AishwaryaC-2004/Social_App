# Social Media App

A simple social media web application built using **Node.js, Express.js, HTML, CSS, JavaScript, and MySQL**.

## Features

* User Registration and Login
* User Profile
* Profile Picture
* Users can change their own profile picture after login
* User Authentication
* MySQL Database Integration

## Technologies Used

* HTML
* CSS
* JavaScript
* Node.js
* Express.js
* MySQL

## How to Run

### 1. Clone the repository

bash
git clone https://github.com/YOUR-USERNAME/social-media-app.git
cd social-media-app


### 2. Install dependencies
bash
npm install


### 3. Configure MySQL

Create the required database and update the database credentials in the project.

### 4. Start the application
npm run dev

Or:

node server.js


Open:

text
http://localhost:3000
